# pidgin-nix

A flake for pidgin and it's plugins, as they were removed from nixpkgs due to depending on really old libraries.

Available packages:

```
pidgin
pidginPackages.
  pidign-carbons
  pidgin-indicator (removed)
  pidgin-latex
  pidgin-opensteamworks
  pidgin-osd
  pidgin-otr
  pidgin-sipe
  pidgin-window-merge
  pidgin-xmpp-receipts
  purple-discord
  purple-facebook (broken)
  purple-googlechat
  purple-lurch
  purple-matrix (removed)
  purple-mm-sms
  purple-plugin-pack (broken)
  purple-slack
  purple-vk-plugin (broken)
  purple-xmpp-http-upload
  tdlib-purple
```
